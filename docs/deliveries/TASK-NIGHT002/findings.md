# 复核边界及问题记录

本包针对固定003B的四路由，不改变任何生产接口、V1迁移或后端跟踪文件。依据 DEC-020/026、ACC-009、frontend-foundation-contract 的已验收值，覆盖 REQ-002/013/014/093、QA-019/029 的开发期认证子集。003D S05–S09 等候选路由不是本轮批准范围。

已确认的问题：工具曾使用 Windows 默认管道编码向 UTF-8 CLI 输入72字节中文口令，夹具创建失败；未把失败计为通过，整体退出1。修正 account() 的 subprocess encoding 为 UTF-8 后重跑受影响套件。不是后端缺陷。首次构建从错误工作目录调用Wrapper失败，后改在backend执行；沙箱阻止Maven缓存写入及localhost连接，经授权升级运行；未降低任何服务验证。

后端缺陷：截至当前真实执行未确认新的后端缺陷。不能据此推导全面安全。

剩余空白：毫秒等号的精确时钟边界未通过真实HTTP冻结时钟验证；状态夹具使用过期值0验证过期分支，30分钟/7天配置和刷新绝对过期不延期另有断言。未做15分钟限流窗口自然流逝/跨窗口恢复；未做SQL断连/提交后响应丢失、操作系统崩溃或数据恢复。重启是自身进程terminate后重新启动；并发屏障同步客户端发起，不声称精确控制数据库锁交错或穷尽调度。没有吞吐量/SLO结论。数据库不变量仅验证本轮两主体的刷新摘要长度和非负代数，不声称全库正确或验证了全部存储约束。业务拒绝的HTTP观察不是完整事务审计。

真实边界：Java CLI、打包服务、HTTP和MySQL为真实运行；认证来源仍 LOCAL_DEV，mode仍 SIMULATED；非微信、短信、Cookie生产方案、真实员工/会员权限、注销、健康数据、支付或前端联调验收。无本轮前端页面及视觉批准图，不涉及页面编码。隐私、生产部署及生产安全接受须独立审批。

若复核发现问题：先保存 results.json（仅白名单字段）并复制脱敏结果；按 case 名定位 run.py 请求构造，使用新随机夹具重放。禁止附加.private日志或HTTP原文；缺陷应记录路线/状态码/确认事实/推断/影响及复现所需前提。不得直接修backend。
