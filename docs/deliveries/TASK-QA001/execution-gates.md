## 阶段阻塞与解锁清单

当前A缺获批页面/可运行前端，B缺获批身份及业务实现、隔离环境，C缺纵向后端与跨端工程，D缺真实资质/部署与专项证据。它们不阻塞本QA规划，不要求UX先完成。已定逻辑可先按独立授权任务开发验证；未批子分支保持阻塞，不将整个项目都锁在外部配置上。

每次交付至少提交需求子项→QA→契约版本→执行记录→缺陷/复核映射，未测项与原因清单、模拟/预留/真实边界、回退及剩余依赖。发现输入冲突或新接口归属先回COORD-01；QA不能擅改生产接口、政策、旧夹具或总台账。验收失败返工原单元，下一门槛仅在COORD-01记录明确结论后推进。
